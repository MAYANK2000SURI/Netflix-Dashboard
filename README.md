## NETFLIX DASHBOARD
This project is a Netflix Dashboard created using Power BI to analyze Netflix’s extensive collection of movies and TV shows. The dashboard provides interactive visualizations and insights into Netflix’s content library, including:

Features:
	1.	Total Movies and TV Shows: Overview of the total number of movies and TV shows available on Netflix.
	2.	Rating Analysis: Distribution of ratings by movies to understand content classification.
	3.	Genre Analysis: Top genres by total shows, highlighting popular categories.
	4.	Release Year Trends: Visualization of the total number of movies released over the years.
	5.	Geographic Distribution: Map showing the count of shows by country.
	6.	Movies vs. TV Shows: Ratio of movies to TV shows with respective counts.

Tools Used:
	•	Power BI: For data visualization and dashboard creation.
	•	Microsoft Bing Maps: For geographic representation of content distribution.

Data Source:

Netflix dataset containing metadata about movies and TV shows, such as genre, rating, release year, and country of availability.

Insights:
	•	Discover the most popular genres and ratings on Netflix.
	•	Analyze trends in content production over the years.
	•	Explore regional distribution of Netflix content.
